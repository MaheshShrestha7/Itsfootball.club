# Project skills

Third-party skills copied in so every Claude session on this repo can use them. Both are MIT licensed.

- `gsap-*` (8 skills): official GSAP skills from https://github.com/greensock/gsap-skills at commit aed9cfd.
- Everything else (21 skills): https://github.com/freshtechbro/claudedesignskills at commit 1da73fe (Three.js, React Three Fiber, Motion, Lottie, Rive and more).

Left out of the second repo: its own `gsap-scrolltrigger` (the official GSAP one has the same name and is newer), `skill-creator`, the `.zip` copies, and the plugin slash commands and agents.

To update, copy the skill folders again from the source repos.
